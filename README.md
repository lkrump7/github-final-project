# github-final-project

This repository hosts the Simple Interest Calculator project for a micro-finance startup that is moving from Subversion (SVN) to Git and GitHub.

The project contains a small shell script that calculates simple interest using the standard formula:

```text
simple interest = (principal * rate * time) / 100
```

## Project Name

Simple Interest Calculator

## Purpose

- Demonstrate a clean first repository on GitHub
- Preserve a simple, easy-to-review example codebase
- Introduce open source project standards such as a license, code of conduct, and contribution guidelines

## About the Simple Interest Calculator

The Simple Interest Calculator is a Bash-based utility that prompts the user for a principal amount, an annual rate of interest, and a time period in years. It then calculates simple interest using the formula:

```text
simple interest = (principal * rate * time) / 100
```

This sample project is intentionally small so the team can focus on learning GitHub repository structure, documentation, licensing, and collaboration workflows.

## Project Contents

- `simple-interest.sh` - sample shell script for simple interest calculation
- `LICENSE` - Apache License 2.0
- `CODE_OF_CONDUCT.md` - community behavior expectations
- `CONTRIBUTING.md` - contribution process and expectations

## Usage

Run the script with:

```bash
bash simple-interest.sh
```

Then provide:

- Principal amount
- Annual interest rate
- Time period

The script prints the calculated simple interest.
