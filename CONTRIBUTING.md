# Contributing Guidelines

Thank you for your interest in contributing to this project.

## How to Contribute

1. Fork the repository.
2. Create a new branch for your change.
3. Make focused updates with clear commit messages.
4. Test your changes before submitting them.
5. Open a pull request that explains what changed and why.

## Contribution Expectations

- Keep changes small and relevant to the project.
- Follow the existing style and structure of the repository.
- Update documentation when behavior or usage changes.
- Be respectful in reviews and discussions.

## Reporting Issues

When opening an issue, include:

- A clear summary of the problem or request
- Steps to reproduce, if reporting a bug
- Expected behavior and actual behavior
- Any relevant logs, screenshots, or context

## Pull Request Checklist

- The change is clearly described
- The code and documentation are updated as needed
- The change has been tested locally
- The pull request is scoped to one logical change

## Review Process

Maintainers will review pull requests for correctness, clarity, scope, and alignment with the project goals. Feedback should be addressed through follow-up commits on the same branch.

## Code of Conduct

By participating in this project, you agree to follow the Code of Conduct in `CODE_OF_CONDUCT.md`.
